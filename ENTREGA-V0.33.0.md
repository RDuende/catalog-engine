# Catalog Engine v0.33.0 — Canonical Product Engine

## Incluye

- Modelo de producto canónico independiente del proveedor.
- Unificación automática de referencias equivalentes mediante puntuación explicable.
- Cola de revisión para coincidencias dudosas.
- Conservación de precio, stock, plazo, MOQ y origen por proveedor.
- Selección de mejor oferta por cantidad, stock, plazo, precio y proveedor preferido.
- Búsqueda sobre el producto unificado.

## Validación

```powershell
npm install
npm run typecheck
npm run test:canonical-product
npm run test:all
```
