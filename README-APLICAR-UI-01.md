# Aplicar UI-01

1. Copia el contenido del parche sobre la raíz del proyecto V3.5.
2. Conserva tus archivos `.env` y datos locales.
3. Ejecuta:

```bash
npm run web:install
npm run web:build
npm run dev
```

En otra terminal:

```bash
npm run web:dev
```

Abre `http://localhost:5173`.

Para validar la entrega completa:

```bash
npm run test:ui-01
```
