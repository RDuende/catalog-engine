# Aplicar UI-02

1. Copia el contenido del ZIP sobre la raíz de UI-01.
2. Conserva tus archivos `.env` y datos de `.data`.
3. Ejecuta:

```bash
npm run web:install
npm run web:build
npm run dev
```

En otra terminal:

```bash
npm run web:dev
```

Abre `http://localhost:5173` y completa una conversación hasta que Rai genere historias. Pulsa **Descubrir historias** para abrir la experiencia de comparación y selección.
