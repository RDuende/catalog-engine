# Checklist de release RCE

## Desarrollo

- [ ] `npm run release:rce:dev`
- [ ] Cambios funcionales probados.
- [ ] Sin regresiones conocidas.

## Publicación

- [ ] Árbol Git limpio.
- [ ] Rama `feature/rce-runtime`.
- [ ] `npm run release:rce:status`
- [ ] `npm run release:rce:prepare`
- [ ] Instalador reversible.
- [ ] Copia de seguridad.
- [ ] Commit y versión actualizados.
