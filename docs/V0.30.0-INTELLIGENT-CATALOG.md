# RecuerdArte Catalog Engine v0.30.0

## Objetivo

La v0.30.0 convierte el catálogo en una base de conocimiento estructurada para Rai. Los datos procedentes de CSV, TSV, Excel, JSON o adaptadores de proveedor se normalizan al mismo modelo canónico antes de persistirse.

## Capacidades incluidas

- Adaptadores CSV, TSV, XLSX, XLS, XLSM, JSON, JSONL, NDJSON y Makito.
- Análisis previo sin escritura mediante `POST /api/v1/imports/analyze`.
- Importación real o simulada mediante `POST /api/v1/imports/run`.
- Productos, variantes, imágenes, categorías y metadatos.
- Taxonomía semántica: destinatarios, intereses, ocasiones, emociones, profesiones, estilos, valores, usos y técnicas de personalización.
- Trazabilidad por trabajo y registro de importación.
- Recuperación de candidatos para Rai mediante `POST /api/v1/catalog/candidates`.

## Flujo recomendado

1. Crear una fuente con `POST /api/v1/imports/sources`.
2. Analizar el archivo con `/imports/analyze`.
3. Ejecutar primero `/imports/run` con `dryRun: true`.
4. Revisar el trabajo con `GET /api/v1/imports/jobs/:jobId`.
5. Repetir con `dryRun: false` para persistir productos.
6. Consultar candidatos con `/catalog/candidates`.

## Ejemplo de búsqueda

```json
{
  "recipient": "padre",
  "interests": ["campo", "senderismo", "naturaleza"],
  "occasions": ["cumpleaños"],
  "limit": 12
}
```

El motor devuelve productos existentes ordenados por coincidencia. Rai debe componer conjuntos únicamente a partir de esos candidatos y nunca inventar artículos.

## Alcance

La extracción directa de catálogos PDF se conectará posteriormente como otro adaptador. El pipeline canónico y la base de datos ya quedan preparados para recibir el resultado del extractor sin duplicar lógica.
