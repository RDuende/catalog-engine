# ADR-018 — Clasificación determinista de intención

## Estado
Aceptada.

## Contexto
Rai necesita identificar qué pretende conseguir la persona antes de seleccionar una política o capacidad. Delegar siempre esta clasificación en un LLM incumpliría el objetivo de Fast Path y reduciría la explicabilidad.

## Decisión
Se incorpora un clasificador determinista, versionado y sin dependencias externas como primer paso de todos los flujos canónicos de `rai-runtime`.

La clasificación se almacena en `RaiContext.conversation.intent`, viaja durante toda la ejecución y se expone en `RuntimeResult`.

## Intenciones iniciales
- GREETING
- CREATE_GIFT
- PERSONALIZE_PRODUCT
- CHOOSE_PRODUCT
- EDIT_IMAGE
- GENERATE_IMAGE
- RESUME_PROJECT
- CHECK_ORDER
- PRODUCT_QUESTION
- HUMAN_SUPPORT
- UNKNOWN

## Consecuencias
- El Fast Path puede decidir sin invocar IA en solicitudes claras.
- Las decisiones son reproducibles y auditables.
- Los mensajes breves pueden heredar la intención previa como continuidad contextual.
- Futuras reglas o clasificadores podrán sustituirse manteniendo el contrato.
