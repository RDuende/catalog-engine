# ADR-027 — Journey Completeness Engine

## Estado
Aceptada.

## Decisión
La completitud de un Journey se calcula mediante perfiles declarativos de requisitos ponderados. Los requisitos se clasifican como obligatorios o recomendados y se resuelven desde hechos estructurados o participantes del agregado.

## Consecuencias
- Rai puede conocer qué falta sin codificar preguntas dentro de cada flujo.
- La preparación para inspiración exige todos los requisitos obligatorios y un umbral de puntuación.
- Los perfiles futuros de cuento, camiseta, bono o evento podrán reutilizar el mismo motor.
- El informe se guarda como un hecho de sistema, manteniendo trazabilidad y versionado.
