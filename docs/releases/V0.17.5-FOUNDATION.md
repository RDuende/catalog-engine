# RecuerdArte Catalog Engine 0.17.5 — Foundation

Esta versión añade cuatro núcleos independientes sin romper las APIs existentes:

- Product DNA: atributos con confianza, procedencia y versión.
- Capability Engine: consulta de capacidades reales de personalización, producción, material y entrega.
- Solution Engine: resolución de intención a solución comercial antes de elegir productos.
- Recipe Engine: recetas versionadas y planes de producción ordenados.

## Validación

```powershell
npm install
npm run typecheck
npm run test:foundation
npm run test
```

## Compatibilidad

La API, Intent Engine, Knowledge Engine y Recommendation Engine existentes permanecen operativos. Los nuevos módulos se exportan desde `src/core/index.ts`.
