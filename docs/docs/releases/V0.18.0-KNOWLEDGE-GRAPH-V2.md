# RecuerdArte Catalog Engine 0.18.0 — Knowledge Graph V2

## Objetivo

Convertir el grafo canónico en una base de conocimiento auditable y preparada para razonamiento.

## Novedades

- Relaciones tipadas ampliables: `BELONGS_TO`, `HAS_ATTRIBUTE`, `RELATED_TO`, `REQUIRES`, `ENABLES` y `SUITABLE_FOR`.
- Peso y confianza independientes en cada relación.
- Procedencia y versión opcionales en entidades y relaciones.
- Snapshot con `schemaVersion`, `graphVersion` y fecha de generación.
- Recorrido ponderado por profundidad, dirección, confianza, peso y tipo de relación.
- Explicaciones legibles de cada camino recorrido.
- Filtro de confianza mínima en consultas de productos.

## Compatibilidad

Los campos V2 son aditivos y opcionales. Los snapshots V1 continúan siendo válidos.
No requiere migración de Prisma.
