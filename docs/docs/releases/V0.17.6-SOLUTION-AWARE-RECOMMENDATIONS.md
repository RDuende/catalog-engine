# RecuerdArte Catalog Engine v0.17.6

## Recomendaciones orientadas a soluciones

La ruta `POST /api/v1/intent/recommend` ya no transforma directamente la intención en una consulta de productos.

El flujo activo es:

`texto -> intención -> solución -> criterios -> productos`

La respuesta incorpora `solutionPlan`, con la solución principal, alternativas, puntuación, razones y capacidades requeridas.

## Catálogo inicial de soluciones

- Regalo emotivo con fotografía.
- Detalle de agradecimiento para docente.
- Recuerdo personalizado para grupo o evento.
- Detalle corporativo personalizado.
- Regalo personalizado de entrega rápida.

Las definiciones están en `src/core/solution/default-definitions.ts` y pueden sustituirse después por datos del Knowledge Graph.

## Compatibilidad

- `/intent/analyze` no cambia.
- `/intent/recommend` conserva `analysis`, `recommendationRequest` y `recommendations`.
- Se añade `solutionPlan` sin eliminar campos anteriores.
- No requiere migración Prisma.
