# V3.5 — Rai Experience UI

## Objetivo

Transformar el frontend funcional de V3.4 en una experiencia conversacional inmersiva y emocional, manteniendo intactos el backend y el Experience SDK.

## Incluye

- Presencia visual etérea de Rai creada con CSS.
- Chat inmersivo con animaciones suaves.
- Timeline visual del Journey: historia, idea, imagen, regalo y compra.
- Estado de pensamiento emocional de Rai.
- Panel vivo del recuerdo con historias, imágenes, mockups y recomendaciones.
- Persistencia local de sesión y credenciales invitadas.
- Recuperación del Journey al recargar la página.
- Diseño responsive y soporte para `prefers-reduced-motion`.

## Validación

```bash
npm run web:install
npm run web:build
npm run test:v3-5
```
