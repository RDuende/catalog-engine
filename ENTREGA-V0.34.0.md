# Catalog Engine v0.34.0 — Semantic Recommendation Engine

## Incluye

- Product DNA determinista derivado del producto canónico.
- Perfil estructurado de recomendación.
- Filtros duros: material, categoría, personalización, stock, MOQ, plazo, presupuesto y sostenibilidad.
- Ranking ponderado configurable.
- Reglas de negocio y proveedores preferentes.
- Selección de la mejor oferta mediante Canonical Product Engine.
- Desglose explicable de puntuación, afinidad y explicación textual reproducible.
- Sobrescrituras de Product DNA para enriquecimiento manual o futuro enriquecimiento mediante IA.

## Validación

```powershell
npm install
npm run typecheck
npm run test:recommendation-engine
```
