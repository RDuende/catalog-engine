# Catalog Engine v0.32.0 — Product Knowledge Graph

## Instalación
Descomprime el ZIP sobre `C:\catalog-engine` y sustituye los archivos.

## Comandos
```powershell
npm install
npm run typecheck
npm run test:knowledge-index
npm run test:knowledge-graph
```

## Incluye
- nodos de producto, familia, categoría, material, proveedor y término;
- relaciones tipadas y ponderadas;
- búsqueda de productos por recorrido del grafo;
- consulta de vecinos;
- detección de productos relacionados y explicación de coincidencias.
