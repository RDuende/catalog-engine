# v0.36.0 — Business Decision Engine

Motor de decisión empresarial modular con scorers enchufables y agregación ponderada.

## Incluye
- MarginScorer
- StockScorer
- DeliveryScorer
- SupplierScorer
- AffinityScorer
- SustainabilityScorer
- StrategyScorer
- perfiles estratégicos externos en JSON
- trazabilidad completa de puntuación y motivos
- sustitución/registro de plugins por dimensión

## Validación
```powershell
npm install
npm run typecheck
npm run test:business-decision
npm run test:recommendation-engine
npm run test:semantic-taxonomy
```
