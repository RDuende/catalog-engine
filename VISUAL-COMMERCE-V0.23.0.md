# Visual Commerce v0.23.0

- Galería visual con fotografías reales del catálogo.
- Selección de modelo por clic.
- Subida de foto desde Rai Playground.
- Mockup inmediato mediante plantillas SVG seguras (llavero, lienzo y genérica).
- Estado de sesión compartido entre conversación, selección y mockup.
- Límite de imagen: 8 MB; PNG, JPEG o WEBP.

La base queda preparada para sustituir o complementar el generador por un proveedor de imágenes IA en una versión posterior, manteniendo la misma API `/api/v1/rai/mockup`.
