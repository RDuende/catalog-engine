# V1.7 — Image Brief Builder

Convierte cada StoryConcept en una dirección visual estructurada y trazable, lista para un proveedor de generación de imágenes.

## Entrega

- contratos `ImageBrief` e `ImageBriefSet`;
- builder determinista sustituible;
- escena, sujetos, composición, paleta, estilo y restricciones;
- semilla de prompt independiente del proveedor;
- guardado versionado como artefacto IMAGE;
- tests y demo del caso de las gemelas.

## Validación

```bash
npm run typecheck
npm run test:v1-7
npm run demo:v1-7
```
