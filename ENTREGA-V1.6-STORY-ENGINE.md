# V1.6 — Story Engine mínimo

Genera tres conceptos narrativos trazables desde un `CreativeBrief` válido.

## Alcance

- Contrato `StoryConcept` y `StoryConceptSet`.
- Proveedor determinista sustituible por LLM.
- Tres direcciones creativas diferenciadas.
- Artefactos `STORY` versionados en el Journey.
- Demo del caso canónico de las gemelas.

## Validación

```bash
npm run typecheck
npm run test:v1-6
npm run demo:v1-6
```
