# Aplicar M2.5

Copia el contenido de este parche sobre la raíz del proyecto M2.4, conservando las rutas.

Después ejecuta:

```bash
npm install
npm run test:m2-5
```

La ruta canónica es `POST /rai-runtime/interact`. La ruta `/rai-runtime/run` sigue disponible temporalmente, pero devuelve cabeceras de deprecación.
