# V3.3 — Experience SDK

Cliente TypeScript independiente de framework para consumir la Experience API y las operaciones principales del recorrido RecuerdArte.

## Incluye

- credenciales USER, GUEST y VOUCHER;
- adopción automática de credenciales invitadas;
- Experience API;
- conversación;
- generación de imágenes y consulta de tareas;
- plantillas y presentaciones;
- catálogo inteligente;
- pedidos e intentos de pago;
- timeout y errores normalizados.

## Pruebas

```bash
npm run typecheck
npm run test:experience-sdk
npm run test:v3-3
```
