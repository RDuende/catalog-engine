# Entrega V1.2 — Discovery Extractor

Convierte mensajes naturales en participantes y hechos estructurados del `JourneyProject`.

## Incluye
- extracción determinista en español;
- destinatarios y gemelos/gemelas;
- edad, relación, ocasión, presupuesto e intención de regalo;
- evidencia y confianza;
- aplicación inmutable al Journey;
- deduplicación básica;
- tests y ADR-026.

## Validación
```bash
npm install
npm run test:v1-2
```
