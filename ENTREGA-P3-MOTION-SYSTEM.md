# P3 — Motion System 1.0

Centraliza el lenguaje de movimiento de RecuerdArte.

## Semántica

- Fade: información nueva.
- Lift: evolución del Journey.
- Focus: una creación pasa de borrador a resultado.
- Confirm: elección del usuario.
- Pulse: acción recomendada.
- Breathing: presencia ambiental de Rai.
