# V1.5 — Creative Brief Builder

Implementa el contrato mínimo y el constructor determinista de CreativeBrief.

## Incluye
- audiencia derivada de participantes RECIPIENT;
- objetivo creativo;
- ocasión y presupuesto;
- objetivos emocionales inferidos con trazabilidad;
- temas e intereses;
- estilos narrativo y visual;
- restricciones y datos pendientes;
- validación mínima;
- artefactos CREATIVE_BRIEF versionados en JourneyProject;
- prueba canónica de las gemelas.

npm run test:v1-5
