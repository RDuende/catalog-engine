# P1 — Design System 1.0

Centraliza la base visual de RecuerdArte sin alterar el flujo funcional de UI-06.

## Incluye

- tokens semánticos para color, tipografía, espaciado, radios, sombras y movimiento;
- tema claro y oscuro desde una única fuente;
- alias compatibles con la interfaz existente;
- fundamentos de accesibilidad y foco visible;
- utilidades de layout;
- componentes React `Button`, `IconButton` y `Surface`;
- respeto global de `prefers-reduced-motion`;
- script `test:p1-design-system`.

## Estructura

`apps/recuerdarte-web/src/design-system/`

- `tokens.css`
- `foundations.css`
- `components.css`
- `components.tsx`
- `index.css`
